# Project Demo Script

1. Run the program from the repository root so data/ paths resolve.
2. Show options 1–5: flight, crew and gate records plus conflict detection.
3. Run options 6 and 7 to demonstrate Merge Sort and Quick Sort; run option 8 or 9 after sorting.
4. Run options 10–12 for Maximum Subarray, Celebrity and Strassen airport connectivity.
5. Run options 13–17 for Activity Selection, Interval Partitioning, Dijkstra, Prim and Kruskal.
6. Open option 18, the Advanced DAA Algorithm Lab.
7. Demonstrate Huffman coding and 0/1 Knapsack using the sample flight/crew data.
8. Demonstrate Matrix Chain, LCS, Optimal BST, Bellman-Ford and Floyd-Warshall.
9. Demonstrate bounded TSP, N-Queens, Subset Sum and all three Branch-and-Bound strategies.
10. Demonstrate Ford-Fulkerson and crew-to-duty-slot bipartite matching; explain the capacity proxy in the README.
11. Demonstrate CRT and compare all four string-matching outputs on the same flight manifest.
12. Export CSV and JSON; then import the sample data/flights.json file using replace mode.
13. Build and run automated tests with CMake and CTest; run the algorithm_benchmark executable.

Suggested closing explanation: the project uses one shared flight/crew/gate dataset and maps DAA algorithms to planning questions. State the assumptions and limitations honestly, especially for route timing and the flow-capacity teaching model.
